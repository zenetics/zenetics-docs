# ZENETICS - Quality Management for the Age of AI

ZENETICS is a quality management (Testing) platform build for mission-critical applications powered by GenAI technology. The platform empowers cross-functional teams of engineers, product managers, and domain experts to collaboratively manage a growing set of test case to ensure that applicatons get tested in depth before they reach production.

With ZENETICS, teams can ship complex AI applications faster and with more confidence to overcome the dreaded **Prototype Gap** that lead to costly rework and delays in the development process.

## Overview of the ZENETICS Platform

The ZENETICS Platform is a cloud-based platform that provides a set of tools and services to help you build, evaluate, and iteratively improve applications with expert feedback. The platform is designed to help you build applications that are reliable, scalable, and secure.

The ZENETICS Platform consists of the following components:

-   **[ZENETICS Portal](https://app.zenetics.io/)**: The ZENETICS Portal scalable application that allows your team of engineers, product managers and domain experts to collaboratively build and optimize reliable LLM applications. It provides access to the Session data captures by the LLM and provides intuitive features to evaluate, analyze and improve the generated output.

-   **[ZENETICS SDK](https://pypi.org/project/zenetics/)**: The ZENETICS SDK for Python provides an easy way to run your test suites managed in ZENTICS on your local development environment or on your continuous integration (CI/CD) system. The SDK comes with command line interface (CLI) tools to enable you to run test suites with a simple command.

## ZENETICS - Key concepts

ZENETICS provides you with the best practices for testing complex GenAI applications. This includes:

-   **Reference Testing**: Testing the output of your AI application against a reference output (also known as Golden Record) to ensure that the application behaves as expected.
-   **AI-Powered Evaluators**: Evaluators automatically analyze the output of your AI application and validate specific perspectives that are cricial to your application (e.g. quality, relevancy, safety, security, privacy, performance).
-   **AI-Assisted User Acceptance Testing**: Modern AI application solve complex business challenges. Integrating domain experts into your projects is key to be succesful. ZENETICS assists human experts in testing by providing tools to analyze the output generated by applications and highlight potential issues.
